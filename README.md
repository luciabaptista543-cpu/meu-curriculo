# Meu Currículo — Site Pessoal

## Estudante
Lúcia Baptista — Licenciatura em Informática.

## Descrição
Site pessoal de currículo/portfólio desenvolvido apenas com HTML5 e CSS3, sem JavaScript e sem frameworks CSS.

## Páginas
- `index.html`: apresentação, foto/avatar, vídeo e áudio.
- `about.html`: formação, competências e tabela de proficiência.
- `portfolio.html`: projetos apresentados em CSS Grid.
- `hobbies.html`: interesses organizados com Flexbox.
- `contact.html`: formulário com validação nativa HTML5.

## Principais recursos
- HTML semântico: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure` e `figcaption`.
- Multimédia: `img`, `video` e `audio`.
- CSS Grid no portfólio.
- Flexbox nos hobbies.
- Variáveis CSS em `:root`.
- Pseudo-classes `:hover`, `:focus`, `:first-child`, `:last-child`, `:nth-child`.
- Pseudo-elemento `::before`.
- `position: sticky`.
- Gradiente, sombras, transições e `@keyframes`.
- Media queries para tablet e telemóvel.
- Validação HTML5 com `required`, `pattern`, `min`, `max`, `minlength` e `maxlength`.

## Como visualizar
Abra `index.html` num navegador. Para o vídeo e áudio, coloque os seus ficheiros em `assets/video/` e `assets/audio/`, respetivamente.

## Observação
Os SVGs incluídos são placeholders. Substitua-os pelas suas fotos, capturas de ecrã e imagem de poster.
